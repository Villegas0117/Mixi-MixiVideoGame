# Musica de los niveles

Las seis pistas proceden de **15 Melodic RPG Chiptunes**, de
**Aureolus_Omicron**. El autor publica la coleccion bajo **CC0 1.0**,
sin requisito de atribucion. Se conservan aqui los creditos por claridad.

- Fuente y declaracion del autor: https://opengameart.org/content/15-melodic-rpg-chiptunes
- Texto de CC0: https://creativecommons.org/publicdomain/zero/1.0/
- Archivos originales OGG, sin modificaciones ni conversion:

| Uso | Composicion original | Archivo en Assets/Resources/Music |
| --- | --- | --- |
| Nivel 1, exploracion | rpgchip03_town | Nivel1/exploracion.ogg |
| Nivel 1, jefe | rpgchip13_battle_1 | Nivel1/boss.ogg |
| Nivel 2, exploracion | rpgchip07_the_shrine_of_mysteries | Nivel2/exploracion.ogg |
| Nivel 2, jefe | rpgchip12_the_evil_one | Nivel2/boss.ogg |
| Nivel 3, exploracion | rpgchip09_rainy_streets | Nivel3/exploracion.ogg |
| Nivel 3, jefe | rpgchip14_battle_2 | Nivel3/boss.ogg |

El autor describe la coleccion como musica melodica para aventura y juegos
de rol preparada para bucle. Son pistas preexistentes, no composiciones
originales creadas para Claw. La adecuacion artistica y la union audible
del bucle necesitan una escucha dentro del juego.
