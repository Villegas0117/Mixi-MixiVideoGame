# Mixi-Mixi

Videojuego de aventura y plataformas 2D protagonizado por Chipotle, un gato que busca rescatar a Piyu. Incluye tres niveles, enemigos, jefes y guardado local.

## Abrir el proyecto

- Unity Editor **6000.3.23f1** con soporte para Linux o Windows.
- Abrir la carpeta del repositorio como proyecto Unity y esperar la importación de los recursos.
- Abrir `Assets/Escenas/MenuPrincipal.unity` y pulsar Play.

## Controles

A/D o flechas: caminar; Shift: correr; Espacio: saltar; E: interactuar; J: garra; mantener y soltar K: bola de pelo; L: lanzar ropa; B: mochila; Esc: pausa.
